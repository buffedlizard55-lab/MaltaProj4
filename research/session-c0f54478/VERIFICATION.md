## Non-featured/low-tier resolution: what is and is not established

- When an exchange has no exact active market, HLTV is consulted for the exact fixture, UTC start, lineup and ranking. Its crowd vote is not odds. The current public explanation says the HLTV betting/analytics pages did not expose a numeric two-way quote for the cited example; this is a limitation, not a zero-percent result.
- Book coverage follows. The 00:10Z snapshot recorded Pinnacle's CS2 endpoint, Thunderpick's page, GG.BET, the BO3.gg upcoming API and EGamersWorld rechecks. HTTP 200 for a page or a fixture listing alone is not a two-sided moneyline. A direct/dated bookmaker line is used only after pair and start-time identity checks and de-vigging; a third-party listing stays labelled as such.
- If no acceptable market line exists, the project originates a separate, labelled VRS estimate from Valve's published points and formula. Valve's 2026 standings directory showed its latest update as 2026-10-05 at this audit; therefore the three current VRS estimates use a 21-day-old standings publication, not a current market consensus. The inputs, formula and calibration are linked on the public [method page](https://buffedlizard55-lab.github.io/MaltaProj4/sources.html#method).
- If neither a valid price nor a supportable model line exists, a research-only pick may appear with **no percentage**, or the row remains unresolved. The open count can therefore be complete without inventing numbers. At this particular observation the unresolved count was 0.
