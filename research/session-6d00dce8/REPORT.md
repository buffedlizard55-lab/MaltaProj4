## Methodology Summary

The site uses a tiered evidence hierarchy:
1. **Exchange gate**: Polymarket validated two-sided quotes (highest confidence)
2. **Bookmaker line**: Pinnacle public API
3. **Wide exchange tier**: Polymarket with wide spreads (lower confidence)
4. **VRS model line**: Valve standings through Valve's published formula
5. **Research rank pick**: HLTV ranking order or one-sided VRS presence (no probability)
6. **Unresolved**: No pick possible (not currently used - all matches have picks)

**Key principle:** No percentage is ever invented. A blank percentage means no validated probability was accepted, never 50/50. Hotspawn crowd votes are never used as a probability source.
