Strategy

Contrarian but not stupid: when an underdog is worth taking

Contrarian is a risk choice, not a scoring bonus. Hotspawn awards points for correct picks by tier; this project has no verified Hotspawn user pick-share data, so a market underdog is not necessarily a crowd underdog. Default to the higher sourced win probability. If you intentionally accept variance for differentiation, limit the swings and require a concrete, sourced matchup, roster, schedule or form reason; this is a project heuristic, not a proven leaderboard edge.
